# Engineering Proposals

This directory contains potential or deferred engineering projects, not
accepted architecture decisions.

A proposal describes a problem, candidate scope, constraints, and questions
that need answering. Its status tracks project readiness, not whether an
architectural decision has been accepted. An approved proposal does not
authorize implementation or settle design choices.

When a proposal is selected for implementation:

1. Agree on scope and acceptance criteria.
2. Record consequential architecture choices in a numbered ADR.
3. Track implementation and delivery in the relevant issue or pull request.
